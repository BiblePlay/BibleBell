BibleBell PUBLIC PORTABLE + PWA 최종판

- 홈: 기존 게임 화면 유지 + 관리자 모드 앞에 '앱 설치' 추가
- 처음 사용: 저장 폴더 지정 안내 표시(나중에 가능)
- 관리자: 데이터 보내기 / 데이터 불러오기 / 저장 위치 지정·변경 / 사용설명서
- 미디어: 제거 후 재등록이 아니라 클릭 또는 '교체'로 바로 바꾸기
- 이동: BibleBell 링크 + BibleBell_Data 폴더 전체
- 백업: 데이터 보내기 시 Excel/JSON/manifest/media/사용안내/웹바로가기 정리
- 재부팅: 같은 브라우저 데이터 유지. 폴더 권한을 다시 묻는 경우 같은 폴더를 다시 허용
- GitHub 업데이트: 사용자가 자기 데이터를 저장한 뒤에는 공개 샘플 100문제가 개인 문제를 덮어쓰지 않음

중요: 이 PUBLIC판은 외장하드의 행사 운영 FINAL 원본과 별도로 사용합니다.
