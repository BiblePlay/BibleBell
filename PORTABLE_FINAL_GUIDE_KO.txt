BibleBell PUBLIC PORTABLE + PWA 최종 구조

1. 웹/PWA 프로그램
- GitHub Pages의 /BibleBell/ 프로그램을 사용합니다.
- manifest + service worker가 포함되어 Chromium 계열 브라우저에서 앱 설치가 가능합니다.
- Home 화면 디자인/구조는 수정하지 않았습니다.

2. 개인 데이터의 이중 보관
- 문제: 브라우저 localStorage에 즉시 저장되어 재부팅 후에도 유지됩니다.
- 이미지/영상/오디오: 브라우저 IndexedDB에 저장되어 재부팅 후에도 유지됩니다.
- 브라우저가 허용하면 persistent storage를 요청하여 임의 정리 위험을 낮춥니다.

3. BibleBell_Data 폴더
- 관리자에서 '내 데이터 저장'을 처음 누르면 사용자가 부모 위치를 직접 고릅니다.
- 선택한 위치 안에 BibleBell_Data 폴더를 자동 생성합니다.
- questions.xlsx / questions.json / manifest.json / media/... 를 저장합니다.
- 폴더를 한 번 연결한 뒤 쓰기 권한이 계속 유지되는 동안 문제 수정은 questions.xlsx와 questions.json에도 자동 반영됩니다.
- 새 미디어 등록도 동일한 BibleBell_Data/media 폴더에 자동 복사됩니다.

4. 재부팅 후
- 브라우저 localStorage/IndexedDB의 개인 데이터가 그대로 남으므로 앱을 다시 열어 계속 사용합니다.
- 운영체제/브라우저 정책에 따라 폴더 쓰기 권한이 다시 'prompt'가 될 수 있습니다. 이 경우 데이터가 사라지는 것이 아니라 폴더 자동 동기화만 멈춥니다. 관리자에서 '내 데이터 저장'을 한 번 누르면 동일 폴더 권한을 다시 승인할 수 있습니다.

5. 다른 컴퓨터로 이동
- BibleBell 웹 링크와 BibleBell_Data 폴더만 가져갑니다.
- 새 컴퓨터에서 BibleBell을 열고 '내 데이터 불러오기'를 누른 뒤 BibleBell_Data 폴더를 선택합니다.
- Excel(우선) 또는 JSON, 미디어를 읽어 브라우저 저장소에 복원합니다.

6. 파일명/경로 규칙
- 미디어는 질문 ID + 용도 기준으로 자동 이름을 만듭니다. 예: Q001-question.jpg, Q001-answer.png, Q001-video.mp4, Q001-audio.mp3
- Excel에는 절대경로가 아닌 /BibleBell/content/media/... 형태의 공통 논리 경로를 기록합니다.
- 카테고리+번호는 문제 자리 주소이며, 그 자리의 문제유형/답변유형/보기/미디어는 자유롭게 바꿀 수 있습니다.

7. 안전 원칙
- 외장하드 FINAL 원본에는 이 PUBLIC 파일을 덮어쓰지 않습니다.
- GitHub 공개용 PUBLIC 전용입니다.
