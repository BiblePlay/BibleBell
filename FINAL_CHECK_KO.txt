[실제 환경에서 마지막으로 확인할 항목]
이 검사 환경에는 npm 패키지 전체 캐시가 없고 외부 npm registry 설치를 완료할 수 없어
실제 npm ci → npm run build 전체 빌드는 이 환경에서 실행 완료하지 못했습니다.
오프라인 npm ci는 yallist 패키지가 캐시에 없어 ENOTCACHED로 중단됨을 확인했습니다.

따라서 GitHub에 업로드한 뒤 Actions에서:
1. build 초록색
2. deploy 초록색
을 확인하면 실제 배포 빌드 검증이 완료됩니다.
