BibleBell PUBLIC FINAL - 최종 점검 요약

[이번 마지막 수정]
1. 전체 데이터 저장의 첫 사용 흐름을 단순화했습니다.
   - 사용자는 바탕화면/문서/USB/외장하드 등 저장할 위치만 선택합니다.
   - BibleBell이 선택한 위치 안에 BibleBell_Data를 자동 생성합니다.
   - 이후 전체 데이터 저장은 같은 BibleBell_Data를 계속 갱신합니다.

2. 전체 데이터 불러오기 기준을 하나로 고정했습니다.
   - 반드시 BibleBell_Data 폴더 자체만 선택합니다.
   - 그 위의 폴더나 media 하위 폴더는 받지 않습니다.

3. 관리자 안내문을 위 규칙에 맞게 정리했습니다.
   - 이동/전달 시 BibleBell 웹주소 + BibleBell_Data 폴더 하나만 필요하다고 명시했습니다.

4. 저장 폴더 열기 버튼을 추가했습니다.
   - 연결된 BibleBell_Data 위치를 시스템 폴더 선택창에서 바로 확인합니다.
   - 웹 브라우저 보안상 Finder/탐색기를 임의로 강제로 실행하지 않습니다.
