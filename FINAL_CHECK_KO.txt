BibleBell PUBLIC FINAL - 최종 점검 기록
검토일: 2026-08-20

[최종 해결 사항]
1. 데이터 보내기
- 폴더 권한/선택은 데이터 보내기 클릭 직후 가장 먼저 처리합니다.
- questions.json을 먼저 저장하고 questions.xlsx를 다음에 저장합니다.
- 안내 파일은 README_BibleBell.txt / APP_URL.txt의 안전한 ASCII 파일명만 사용합니다.
- 안내 파일 생성 실패는 핵심 데이터 내보내기를 중단시키지 않습니다.
- 미디어 한 개 저장 실패로 기존 media 폴더 전체를 삭제하지 않습니다.
- manifest.json은 문제/Excel/미디어 저장 시도가 끝난 마지막 단계에 기록합니다.
- 권한이 유지되지 않으면 같은 BibleBell_Data 또는 원하는 부모 위치를 다시 선택할 수 있습니다.

2. 이미지/영상/오디오 교체
- 기존 미디어를 휴지통으로 먼저 지울 필요가 없습니다.
- 이미지 미리보기/깨진 이미지 안내 영역을 클릭하면 바로 새 이미지로 교체됩니다.
- 영상·오디오는 파일명/안내 영역 또는 드래그앤드롭으로 바로 교체됩니다.
- 별도의 선택/교체 버튼은 추가하지 않았고 휴지통은 완전 삭제 용도로만 남겼습니다.
- 동일한 Qxxx-question / Qxxx-answer 파일명으로 교체해도 revision/브라우저 저장소를 통해 새 미리보기가 갱신됩니다.

3. BibleBell_Data 이동/복원
- 프로그램은 웹/PWA, 사용자 데이터는 브라우저 + BibleBell_Data로 분리합니다.
- 다른 컴퓨터에서는 BibleBell 웹 + BibleBell_Data 폴더로 복원합니다.
- questions.json / questions.xlsx 중 더 최근에 수정된 정상 파일을 우선 읽고 다른 파일을 복구 경로로 사용합니다.
- 절대경로 대신 /BibleBell/content/media/... 규칙을 사용합니다.

4. PWA
- 홈의 앱 설치 버튼은 관리자 모드 바로 앞에 있습니다.
- beforeinstallprompt가 있으면 브라우저 공식 설치창을 호출합니다.
- 자동 설치창이 없는 환경에서만 브라우저별 안내를 표시합니다.
- service worker는 v7-final 캐시로 갱신했고 HTML/JS/CSS는 온라인에서 네트워크 우선으로 읽어 이전 캐시가 새 수정본을 가리는 위험을 줄였습니다.
