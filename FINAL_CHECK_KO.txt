BibleBell PUBLIC FINAL - 최종 점검 기록
검토일: 2026-08-20

[이번 최종 동결에서 해결한 핵심]
1. 저장 위치 기억 / 전체 데이터 저장
- 저장 위치 지정은 최초 한 번 또는 사용자가 명시적으로 위치를 바꿀 때만 폴더 선택창을 엽니다.
- 선택한 BibleBell_Data FileSystemDirectoryHandle은 IndexedDB에 저장하고 실행 중에는 메모리 캐시도 사용합니다.
- 전체 데이터 저장 시 기존 핸들의 쓰기 권한이 granted이면 폴더 선택창 없이 같은 BibleBell_Data에 바로 저장합니다.
- 권한이 prompt로 돌아온 경우 새 폴더를 선택시키지 않고 기존에 연결한 같은 BibleBell_Data의 권한만 다시 요청합니다.
- denied/손상된 연결일 때만 관리자 '저장 위치 변경'에서 사용자가 명시적으로 다시 연결하도록 안내합니다.
- questions.json -> questions.xlsx -> 미디어 저장 시도 -> manifest.json 마지막 기록 순서를 유지합니다.
- 일부 미디어 또는 선택적 안내 파일 실패 때문에 기존 media 폴더 전체를 삭제하지 않습니다.

2. 버튼 이름/역할
- '데이터 보내기' -> '전체 데이터 저장'
- '데이터 불러오기' -> '전체 데이터 불러오기'
- '저장 위치 지정/변경'은 루트 BibleBell_Data 연결 전용입니다.
- Excel 가져오기/엑셀 다운로드는 기존 기능 그대로 유지합니다.

3. 미디어 즉시 교체
- 기존 이미지가 있어도 휴지통으로 먼저 삭제하지 않습니다.
- 이미지 미리보기 또는 깨진 이미지 안내 영역 클릭 -> 새 파일 선택 -> 즉시 교체합니다.
- 영상/오디오는 안내/파일명 영역 클릭 또는 drag & drop으로 교체합니다.
- 새 파일을 브라우저/연결 폴더에 먼저 저장한 뒤 같은 문제/용도의 이전 확장자 변형을 정리합니다.
- 휴지통은 완전 삭제 용도로만 남겨 두었습니다.
- 별도의 '선택/교체' 버튼은 추가하지 않았습니다.

4. 바탕화면 바로가기
- 홈의 관리자 모드 앞 버튼은 '바로가기 만들기'입니다.
- Mac: BibleGoldenBell.webloc 다운로드
- Windows: BibleGoldenBell.url 다운로드
- Windows .url에는 공개 BibleBell 아이콘 URL을 지정하며 사이트에도 favicon.ico를 포함했습니다.
- 바로가기는 https://bibleplay.github.io/BibleBell/ 홈 주소만 엽니다. /admin 직접 링크로 고정하지 않습니다.
- PWA는 필수 흐름에서 제거했으며 manifest/service worker는 원하는 사용자의 브라우저 공식 PWA 설치를 위해 그대로 유지합니다.

5. 이동/복원
- 같은 컴퓨터/같은 브라우저에서는 localStorage/IndexedDB가 평소 작업을 유지합니다.
- 안전한 백업/이동 기준은 BibleBell_Data 전체입니다.
- 다른 컴퓨터에서는 BibleBell 웹 -> 관리자 -> 전체 데이터 불러오기 -> 가져온 BibleBell_Data 선택으로 복원합니다.
- questions.json/questions.xlsx가 모두 있으면 더 최신인 정상 파일을 우선 사용하고 손상 시 다른 파일을 복구 경로로 사용합니다.
