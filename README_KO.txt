도전 바이블 골든벨 PUBLIC 최종 사용 구조

1. 프로그램
- GitHub Pages의 BibleBell이 공통 프로그램입니다.
- 홈의 '앱 설치'로 지원 브라우저에서 웹앱(PWA)으로 설치할 수 있습니다.

2. 내 데이터
- 같은 컴퓨터/브라우저의 수정 내용은 브라우저 저장소에 유지됩니다.
- 처음 저장 위치를 지정하면 선택한 위치 안에 BibleBell_Data가 자동 생성됩니다.
- 연결 권한이 유지되는 동안 문제 수정은 questions.json에도 자동 반영됩니다.
- '데이터 보내기'를 누르면 questions.xlsx / questions.json / manifest.json / media가 최신 상태로 정리됩니다.

3. 다른 컴퓨터로 이동
- BibleBell_Data 폴더 전체를 복사합니다.
- 새 컴퓨터에서 https://bibleplay.github.io/BibleBell/ 을 엽니다.
- 관리자 모드 > 데이터 불러오기 > 가져온 BibleBell_Data를 선택합니다.
- 자동 저장된 최신 questions.json을 우선 읽고, Excel은 관리·복구용으로 함께 보관됩니다. 그림/영상/오디오 연결도 복원됩니다.

4. Excel
- Excel은 문제유형, 답변유형, 문제, 정답, 보기1~4, 힌트, 이미지/미디어 경로를 보관합니다.
- 정렬 후 다시 가져와도 카테고리+번호 기준으로 원래 자리로 복원됩니다.
- Excel만 옮기면 미디어 파일 자체는 이동하지 않으므로, 완전한 이동에는 BibleBell_Data 전체를 사용합니다.

5. 미디어
- 기존 파일을 먼저 제거하지 않아도 새 파일을 선택하면 바로 교체할 수 있습니다.
- 파일명은 문제 ID + 용도 규칙으로 자동 정리됩니다.
- 깨진 이미지가 있으면 교체 안내가 표시됩니다.

6. 앱 아이콘
- PWA 설치 후 독립 창으로 실행됩니다.
- 바탕화면 아이콘의 자동 생성 위치는 운영체제/브라우저가 결정합니다.
- 바탕화면에 바로 보이지 않으면 앱/응용 프로그램 목록에서 BibleBell을 찾아 Dock, 작업표시줄 또는 바로가기로 추가하세요.

7. 바탕화면 바로가기 보조
- 운영체제/브라우저가 PWA 아이콘을 바탕화면에 자동 배치하지 않는 경우가 있습니다.
- 데이터 보내기 후 BibleBell_Data 안에 생성되는 BibleBell_실행.url(Windows), BibleBell_실행.webloc(Mac)을 바탕화면에 복사하면 웹주소를 한 번에 열 수 있습니다.
