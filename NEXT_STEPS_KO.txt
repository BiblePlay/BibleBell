도전 바이블 골든벨 수정본 실행 순서

1. 이 폴더를 기존 원본에 덮어쓰지 말고 별도 위치에 둡니다.
2. 터미널에서 이 폴더로 이동합니다.
3. npm install
4. npm run dev
5. 브라우저에서 http://localhost:5173/BibleBell/ 접속
6. 관리자에서 숨은그림 1번 문제/정답 이미지가 보이는지 확인
7. 문제 문장을 한 글자 수정하고 저장
8. 새로고침 후 유지되는지 확인
9. 서버 종료(Control+C) 후 다시 npm run dev
10. 수정 내용과 이미지가 유지되는지 확인

중요:
- 문제 데이터: content/questions.json
- 이전 문제 백업: content/backups/questions-previous.json
- 이미지: content/media/images
- 영상: content/media/videos
- 음원: content/media/audio
- 관리자에서 파일을 선택하면 이름은 자동으로 Q번호 기반으로 저장됩니다.
