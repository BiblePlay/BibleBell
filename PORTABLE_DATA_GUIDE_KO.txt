BibleBell PUBLIC - 개인 데이터 폴더 기능

목적
- GitHub Pages는 프로그램 틀만 제공합니다.
- 사용자의 문제/그림/영상/오디오는 각 사용자 브라우저와 BibleBell_Data 폴더에 저장합니다.
- AI 없이 고정 규칙으로 미디어 파일명을 만듭니다.

미디어 파일명 규칙 (기존 로컬 API와 동일)
- Q001-question.jpg : 문제 이미지
- Q001-answer.png    : 정답 이미지
- Q001-video.mp4     : 동영상
- Q001-audio.mp3     : 오디오
- 확장자는 실제 등록 파일 형식을 유지합니다.

Excel에 기록되는 경로 예
/BibleBell/content/media/images/Q001-question.jpg
/BibleBell/content/media/videos/Q001-video.mp4

BibleBell_Data 구조
BibleBell_Data/
  questions.xlsx
  questions.json
  manifest.json
  media/
    images/
    videos/
    audio/

웹 사용 순서
1. GitHub Pages의 BibleBell을 엽니다.
2. 관리자에서 문제와 미디어를 수정합니다.
3. "내 데이터 저장"을 누릅니다.
   - 최초 1회: 저장할 상위 폴더를 고르면 프로그램이 그 안에 BibleBell_Data를 만듭니다.
   - 이후: 권한이 유지되면 같은 폴더에 한 번 클릭으로 갱신합니다.
4. 다른 컴퓨터로 이동할 때 BibleBell_Data 폴더 하나만 복사합니다.
5. 새 컴퓨터에서 같은 웹을 열고 "내 데이터 불러오기"를 누른 뒤 BibleBell_Data 폴더를 선택합니다.
6. 문제 100개와 미디어 연결이 복원됩니다.

저장 원칙
- GitHub 서버에는 개인 미디어를 업로드하지 않습니다.
- 웹에서 등록한 미디어는 IndexedDB에도 저장되므로, 데이터 폴더를 아직 지정하지 않아도 현재 브라우저에서는 유지됩니다.
- "내 데이터 저장" 시 문제 Excel/JSON/미디어를 함께 내보냅니다.
- 공개웹에서 사용자가 자기 데이터를 저장한 뒤에는 GitHub의 샘플 100문제가 사용자 데이터를 덮어쓰지 않습니다.

브라우저
- 폴더 직접 저장/복원 기능은 Chrome / Edge / Whale 등 Chromium 계열 데스크톱 브라우저를 기준으로 합니다.
- 브라우저 보안상 최초 폴더 선택/권한 승인은 사용자가 직접 해야 합니다.

기존 기능 보존
- Home 화면, 점수판, 카테고리, 100문제 구조, Excel Import/Export, 기존 로컬 Vite API를 유지합니다.
- 로컬 앱에서는 기존 /BibleBell/api/questions 및 /BibleBell/api/media를 우선 사용합니다.
- GitHub Pages에서 API가 없을 때만 브라우저 로컬 저장 방식으로 자동 전환합니다.
