도전 바이블 골든벨 PUBLIC FINAL 사용안내

[핵심]
BibleBell 프로그램은 웹에서 실행됩니다.
내가 수정한 문제와 미디어는 같은 컴퓨터의 브라우저에 유지되며, BibleBell_Data 폴더에 실제 백업/이동용 데이터로 저장할 수 있습니다.
다른 컴퓨터로 옮길 때는 BibleBell 웹주소 + BibleBell_Data 폴더 전체를 함께 가져가면 됩니다.

1. 바로가기 만들기
- 홈의 '바로가기 만들기'를 누릅니다.
- Mac: BibleGoldenBell.webloc
- Windows: BibleGoldenBell.url
- 다운로드된 BibleGoldenBell 파일을 바탕화면에 옮겨 두고 더블클릭하면 BibleBell 웹이 바로 열립니다.
- PWA 설치는 필수가 아닙니다.

2. 저장 위치
- 관리자 모드에서 '저장 위치 지정'을 처음 한 번 누릅니다.
- Documents, Desktop, USB, 외장하드 등 원하는 위치를 선택할 수 있습니다.
- BibleBell이 그 안에 BibleBell_Data 폴더를 자동으로 만들고 폴더 연결정보를 기억합니다.
- 다음 접속부터는 같은 저장 위치를 자동으로 재사용합니다.
- 브라우저가 보안상 권한만 다시 물을 때는 기존 BibleBell_Data에 대한 권한만 다시 허용하면 됩니다. 새 폴더를 다시 고를 필요는 없습니다.

3. 문제 편집
- 카테고리 + 번호가 문제의 위치입니다.
- 문제유형과 답변유형은 샘플에 고정되어 있지 않습니다.
- 어느 자리든 일반/OX/그림/인물/영상/숨은그림과 단답/객관식으로 변경할 수 있습니다.
- 객관식 보기1~4도 Excel에 함께 저장됩니다.

4. 그림·영상·오디오
- 기존 파일을 먼저 삭제할 필요가 없습니다.
- 이미지는 미리보기/깨진 이미지 안내 영역을 클릭하면 바로 새 파일로 교체됩니다.
- 영상·오디오는 파일명/안내 영역을 클릭하거나 파일을 끌어 놓으면 바로 교체됩니다.
- 휴지통은 파일을 완전히 삭제할 때만 사용합니다.
- BibleBell이 문제 ID 기준의 안정적인 파일명으로 정리합니다.

5. Excel
- '엑셀 다운로드'는 현재 100문제를 관리용 Excel로 내보냅니다.
- Excel을 정렬해도 다시 불러올 때 카테고리+번호 기준으로 원래 위치에 들어갑니다.
- Excel만 이동하면 실제 미디어 파일은 따라가지 않습니다.

6. 전체 데이터 저장
- 중요한 작업을 마친 뒤 관리자 모드의 '전체 데이터 저장'을 누릅니다.
- 이미 저장 위치가 연결되어 있고 권한이 유지되면 폴더 선택창 없이 바로 같은 BibleBell_Data에 저장합니다.
- 권한이 prompt 상태라면 새 위치 선택이 아니라 기존 BibleBell_Data에 대한 권한 허용만 요청합니다.
- BibleBell_Data에는 questions.xlsx, questions.json, manifest.json, media/images, media/videos, media/audio가 최신화됩니다.
- 미디어 한 파일을 읽지 못했다는 이유로 기존 media 폴더 전체를 자동 삭제하지 않습니다.

7. 다른 컴퓨터로 이동
- BibleBell_Data 폴더 전체를 USB·외장하드·클라우드 등으로 복사합니다.
- 새 컴퓨터에서 BibleBell 웹을 엽니다.
- 관리자 모드 → '전체 데이터 불러오기' → 가져온 BibleBell_Data 선택
- 문제와 미디어가 같은 문제 위치로 복원됩니다.

8. 컴퓨터를 껐다 켠 뒤
- 같은 컴퓨터·같은 브라우저의 사이트 데이터가 유지되면 문제 수정 내용과 브라우저 미디어 저장소는 그대로 유지됩니다.
- 저장 폴더 핸들도 기억하며 권한이 유지되면 자동으로 같은 폴더를 사용합니다.
- 안전한 백업/이동 기준은 BibleBell_Data 폴더입니다.

9. 선택적 PWA 설치
- PWA 설치는 필수 기능이 아닙니다. 원하는 사용자는 Chrome/Edge/Whale/Safari의 공식 웹앱 설치 기능을 별도로 사용할 수 있습니다.

10. 문제가 생겼을 때
- 이미지가 안 보이면 해당 미디어 영역을 클릭해 새 파일로 바로 교체하세요.
- 다른 컴퓨터에서 미디어가 안 보이면 Excel만 가져온 것은 아닌지 확인하고 BibleBell_Data 전체를 '전체 데이터 불러오기'로 복원하세요.
- 저장 폴더 권한을 잃은 경우 기존 데이터가 지워지는 것이 아닙니다. 관리자에서 같은 저장 위치를 다시 연결하면 됩니다.
