도전 바이블 골든벨 PUBLIC FINAL 사용안내

[핵심]
BibleBell 프로그램은 웹/PWA로 실행됩니다.
내가 수정한 문제와 미디어는 내 컴퓨터에 보관할 수 있습니다.
다른 컴퓨터로 옮길 때는 BibleBell 웹주소 + BibleBell_Data 폴더 전체를 함께 가져가면 됩니다.

1. 처음 시작
- https://bibleplay.github.io/BibleBell/ 을 엽니다.
- 홈의 '앱 설치' 버튼을 누릅니다.
- 브라우저가 설치창을 지원하면 공식 PWA 설치창이 뜹니다.
- 설치창을 직접 띄울 수 없는 환경에서는 버튼이 현재 브라우저에 맞는 방법을 안내합니다.

2. 저장 위치
- 관리자 모드에서 '저장 위치 지정'을 누릅니다.
- Documents, Desktop, USB, 외장하드 등 원하는 위치를 선택할 수 있습니다.
- 선택한 부모 폴더 이름은 자유입니다.
- BibleBell이 그 안에 BibleBell_Data 폴더를 자동으로 만듭니다.
- 폴더 기능이 지원되지 않는다는 안내가 나오면 Chrome, Edge, Whale 같은 지원 브라우저에서 사용하세요.

3. 문제 편집
- 카테고리 + 번호가 문제의 위치입니다.
- 문제유형과 답변유형은 샘플에 고정되어 있지 않습니다.
- 어느 자리든 일반/OX/그림/인물/영상/숨은그림과 단답/객관식으로 변경할 수 있습니다.
- 객관식 보기1~4도 Excel에 함께 저장됩니다.

4. 그림·영상·오디오
- 기존 파일을 먼저 제거하지 않아도 됩니다.
- 미디어 영역 또는 '교체'를 눌러 새 파일을 선택하면 같은 문제 자리의 파일로 교체됩니다.
- BibleBell이 문제 ID 기준의 일정한 파일명으로 정리합니다.
- Excel/JSON에는 다른 컴퓨터에서도 다시 찾을 수 있는 연결 경로가 기록됩니다.

5. Excel
- '엑셀 다운로드'는 현재 100문제를 관리용 Excel로 내보냅니다.
- Excel을 정렬해도 다시 불러올 때 카테고리+번호 기준으로 원래 위치에 들어갑니다.
- Excel만 이동하면 실제 미디어 파일은 따라가지 않습니다.

6. 데이터 보내기
- 중요한 작업을 마친 뒤 관리자 모드의 '데이터 보내기'를 누르세요.
- BibleBell_Data에 다음 항목이 최신화됩니다.
  questions.xlsx
  questions.json
  manifest.json
  media/images
  media/videos
  media/audio
  BibleBell_사용안내.txt
- 미디어 한 파일을 읽지 못했다는 이유로 기존 media 폴더 전체를 자동 삭제하지 않습니다.

7. 다른 컴퓨터로 이동
- BibleBell_Data 폴더 전체를 USB·외장하드·클라우드 등으로 복사합니다.
- 새 컴퓨터에서 BibleBell 웹을 엽니다.
- 관리자 모드 → '데이터 불러오기'
- 가져온 BibleBell_Data 폴더 자체 또는 그 바로 위 폴더를 선택합니다.
- 권한을 물으면 허용합니다.
- 문제와 미디어가 같은 문제 위치로 복원됩니다.

8. 컴퓨터를 껐다 켠 뒤
- 같은 컴퓨터·같은 브라우저의 사이트 데이터가 유지되면 문제 수정 내용과 브라우저 미디어 저장소가 그대로 유지됩니다.
- 브라우저가 BibleBell_Data 폴더 권한을 다시 물으면 같은 폴더를 다시 허용하세요.
- 안전한 백업/이동 기준은 BibleBell_Data 폴더입니다.

9. 앱 설치
- BibleBell은 .exe나 .dmg를 별도로 설치하는 방식이 아니라 브라우저 공식 PWA 기능을 사용합니다.
- Chrome/Edge/Whale: 홈의 앱 설치 버튼을 먼저 사용하세요.
- Mac Safari: 파일 → Dock에 추가
- 설치 아이콘이 바탕화면에 자동으로 생기는 위치는 운영체제/브라우저 정책에 따라 다를 수 있습니다.
- 설치 후 앱 목록/Dock/시작 메뉴 등에서 BibleBell 아이콘으로 실행할 수 있습니다.

10. 문제가 생겼을 때
- 이미지가 안 보이면 관리자에서 해당 미디어를 새 파일로 교체하세요.
- 다른 컴퓨터에서 미디어가 안 보이면 Excel만 가져온 것은 아닌지 확인하고 BibleBell_Data 전체를 '데이터 불러오기'로 복원하세요.
- 저장 폴더 권한을 잃은 경우 기존 데이터가 지워지는 것이 아니라 같은 BibleBell_Data 폴더를 다시 허용하면 됩니다.
