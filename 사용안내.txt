도전 바이블 골든벨 PUBLIC FINAL 사용안내

[핵심]
BibleBell 프로그램은 웹에서 실행됩니다.
내가 수정한 문제와 미디어는 같은 컴퓨터의 브라우저에 유지되며, BibleBell_Data 폴더에 실제 백업/이동용 데이터로 저장할 수 있습니다.
다른 컴퓨터로 옮길 때는 BibleBell 웹주소 + BibleBell_Data 폴더 하나만 함께 가져가면 됩니다.

1. 바로가기 만들기
- 홈의 '바로가기 만들기'를 누릅니다.
- Mac: BibleGoldenBell.webloc
- Windows: BibleGoldenBell.url
- 다운로드된 BibleGoldenBell 파일을 바탕화면에 옮겨 두고 더블클릭하면 BibleBell 웹이 바로 열립니다.
- PWA 설치는 필수가 아닙니다.

2. 처음 전체 데이터 저장
- 문제를 수정하거나 그림·영상·오디오를 넣은 뒤 '전체 데이터 저장'을 누릅니다.
- 처음 한 번만 바탕화면, 문서, USB, 외장하드 등 저장할 위치를 선택합니다.
- 폴더를 미리 만들거나 BibleBell_Data라는 이름을 직접 정할 필요는 없습니다.
- BibleBell이 선택한 위치 안에 항상 'BibleBell_Data' 폴더와 media/images, media/videos, media/audio 기본 폴더를 자동 생성합니다.
- 이후 전체 데이터 저장은 같은 BibleBell_Data 폴더를 계속 최신 상태로 갱신합니다.

3. BibleBell_Data 안에 저장되는 것
- questions.xlsx : 사람이 열어 보고 수정할 수 있는 100문제 Excel
- questions.json : BibleBell이 정확하게 현재 문제 상태를 복원하는 데이터
- manifest.json : 데이터 묶음 정보
- media/images : 문제·정답 이미지
- media/videos : 영상
- media/audio : 오디오

4. 저장 폴더 확인
- 저장 위치가 연결되면 관리자 화면에 '저장 폴더 열기'가 표시됩니다.
- 이 버튼으로 현재 연결된 BibleBell_Data 위치를 시스템 폴더 창에서 확인할 수 있습니다.
- 웹 브라우저 보안상 Finder/탐색기를 임의로 강제 실행하는 방식은 사용하지 않습니다.
- 저장 위치를 바꾸고 싶을 때만 '저장 위치 변경'을 사용합니다.

5. 문제 편집
- 카테고리 + 번호가 문제의 위치입니다.
- 문제유형과 답변유형은 샘플에 고정되어 있지 않습니다.
- 어느 자리든 일반/OX/그림/인물/영상/숨은그림과 단답/객관식으로 변경할 수 있습니다.
- 객관식 보기1~4도 Excel에 함께 저장됩니다.

6. 그림·영상·오디오
- 기존 파일을 먼저 삭제할 필요가 없습니다.
- 이미지는 미리보기/깨진 이미지 안내 영역을 클릭하면 바로 새 파일로 교체됩니다.
- 영상·오디오는 파일명/안내 영역을 클릭하거나 파일을 끌어 놓으면 바로 교체됩니다.
- 휴지통은 파일을 완전히 삭제할 때만 사용합니다.
- BibleBell이 문제 ID 기준의 안정적인 파일명으로 정리합니다.

7. Excel
- '엑셀 다운로드'는 현재 100문제를 관리용 Excel로 내보냅니다.
- Excel을 정렬해도 다시 불러올 때 카테고리+번호 기준으로 원래 위치에 들어갑니다.
- Excel만 이동하면 실제 미디어 파일은 따라가지 않습니다.

8. 전체 데이터 저장
- 이미 BibleBell_Data가 연결되어 있고 권한이 유지되면 폴더 선택창 없이 같은 폴더에 바로 저장합니다.
- 브라우저가 권한만 다시 확인하면 기존 BibleBell_Data에 대한 권한만 허용합니다.
- questions.xlsx, questions.json, manifest.json과 media 폴더가 최신화됩니다.
- 미디어 한 파일을 읽지 못했다는 이유로 기존 media 폴더 전체를 자동 삭제하지 않습니다.

9. 다른 컴퓨터로 이동
- BibleBell_Data 폴더 전체를 USB·외장하드·클라우드 등으로 복사합니다.
- 새 컴퓨터에서 BibleBell 웹을 엽니다.
- 관리자 모드 → '전체 데이터 불러오기'를 누릅니다.
- 반드시 가져온 'BibleBell_Data' 폴더 자체를 선택합니다.
- 그 위 폴더나 media/images 같은 하위 폴더를 선택하지 않습니다.
- 문제와 미디어가 같은 문제 위치로 복원됩니다.

10. 컴퓨터를 껐다 켠 뒤
- 같은 컴퓨터·같은 브라우저의 사이트 데이터가 유지되면 문제 수정 내용과 브라우저 미디어 저장소는 그대로 유지됩니다.
- BibleBell은 연결했던 BibleBell_Data 폴더 핸들도 기억합니다.
- 권한이 유지되면 같은 폴더를 그대로 사용합니다.
- 브라우저가 보안상 권한을 다시 묻는 경우에는 기존 폴더에 대한 권한만 다시 허용하면 됩니다.

11. 꼭 기억하세요
- 저장할 위치는 자유입니다.
- 실제 데이터 폴더 이름은 항상 BibleBell_Data로 BibleBell이 자동 생성합니다.
- 다른 컴퓨터로 옮길 때는 BibleBell 웹주소 + BibleBell_Data 폴더 하나면 됩니다.
- BibleBell_Data 내부 파일명과 media 폴더 구조는 프로그램이 관리하므로 임의로 바꾸지 않는 것을 권장합니다.
